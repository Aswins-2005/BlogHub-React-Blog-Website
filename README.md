# BlogHub – React Blog Website

BlogHub is a responsive blog website built using React.js. It allows users to browse blogs by category and view individual blog posts through dynamic routing.

## Features

- Browse all blog posts.
- Category-based blog filtering.
- Individual blog detail pages.
- Navigation using React Router.
- Reusable React components.
- Search bar UI.
- Responsive layout for desktop, tablet, and mobile.
- Hover effects and modern UI styling.

## Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- React Router DOM
- Font Awesome

## Installation and Setup

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Navigate to the project folder:

```bash
cd bloghub
```

3. Install dependencies:

```bash
npm install
```

4. Start the development server:

```bash
npm run dev
```

5. Open the local URL displayed in your terminal.
